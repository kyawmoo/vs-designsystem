Alert

Inline message box in four tones. Implemented in react/src/components/Alert.tsx and blade/components/vs-alert.blade.php (wraps the site's .alert).

Tones

Fill and border come from the status tokens. The text and icon use the heading/body text colours, never the border colour (the yellow border is 1.4:1 on its own fill). Text contrast on the fills is 11.0–13.2:1 (body) and 14.0–16.8:1 (heading).

Heads up

A new report is ready to view.

Saved

Your changes were saved successfully.

Subscription about to expire

Renew it before the end of the month to keep your downloads.

Verification required

Upload your documents to continue.

Usage — React

import { Alert } from '@vectorsticker/design-system'; <Alert tone="warning" title="Subscription about to expire" onDismiss={close}>Renew it before the end of the month.</Alert>

Usage — Blade

<x-vs-alert tone="danger" :title="translate('KYC Verification Required')" class="mb-0">...</x-vs-alert>

Wraps the real Bootstrap .alert .alert-{tone} markup that 6 workspace views use today (10 uses), so it looks the same, and adds role="alert" (warning, danger) or role="status" (info, success). The reports dashboard has about 6 hand-written error/notice boxes this can replace.

Props

PropValuesToken
toneinfo (default) · success · warning · danger--vs-color-{tone}-bg, -border
titleoptional bold first line (Blade: <h4 class="alert-heading">)
iconReact only: replaces the tone icon, false hides it
onDismiss / dismissibleReact: callback shows a dismiss button. Blade: boolean, Bootstrap's own close button

Accessibility

warning and danger are announced at once (role="alert"); success and info politely (role="status"). The icon is decorative. The dismiss button has an accessible name and the focus ring from the focus tokens.
