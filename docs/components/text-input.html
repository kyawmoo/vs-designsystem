06 // One-System Gap

⚠ Public vs Admin

Radius and focus ring differ.

Public site 8px · no focus ring

.form-control: 8px radius, 1px #ECECEC, focus = green border, box-shadow: none.

Admin panel 2px · visible ring

.form-control: 0.125rem (2px) radius, 1px #ced4da, focus = 0 0 0 1px var(--primary_color).

08 // Guidelines

Do’s and Don’ts

$input-guidelines

DOPut a visible label above every field.
DON’TDon’t use the placeholder as the only label — it disappears as soon as someone types.
DOMake disabled fields visibly grey.
DON’TDon’t make disabled fields look identical to active ones.
