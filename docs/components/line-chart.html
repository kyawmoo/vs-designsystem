Line Chart

Animated time-trend chart on Chart.js, with the chart rules built in: one point per day, today marked, exactly one empty day after today, and a missing day drawn as a gap, never as 0. Plus AnimatedNumber for the KPI value above a sparkline.

02 // Rules

Chart rules (built in)

RuleHow the component does it
One point per dayThe axis is every calendar day from the first date to one day after today
Today markedDotted vertical line and a bold (Today) label in --vs-chart-today; that label is never thinned out
Exactly 1 empty future dayThe axis ends one day after today, with no value
Missing data is a gapA day with no value is null and the line breaks (spanGaps: false)
Regular legendSwatch + short label per series, above the chart (none for sparklines)
Reduced motionNo animation when the user asks for reduced motion

Usage — React

import { LineChart, AnimatedNumber } from '@vectorsticker/design-system'; // chart.js ^4.4 is a peer dependency (the reports dashboard already has it) <LineChart ariaLabel="Daily downloads, last 30 days" dates={rows.map(r => r.date)} // "YYYY-MM-DD" series={[{ id: 'dl', label: 'Downloads', data: rows.map(r => r.downloads) }]} /> <AnimatedNumber value={4214} /> <LineChart variant="sparkline" ariaLabel="Downloads trend" dates={dates} series={series} />
