05 // Guidelines

Do’s and Don’ts

$radio-guidelines

DOUse radio buttons only when exactly one option must be selected.
DON’TDon’t use radios when several choices are valid — use checkboxes instead.
DOPre-select a sensible default when one exists.
DON’TDon’t leave a required group with nothing selected.
