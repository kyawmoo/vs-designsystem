Weekly Column Chart

One stacked column per week, for weekly numbers that cannot be added up from days (distinct visitors, a returning rate), with change markers on the axis (issue #150). React only; plain HTML, no chart library. For one column per day use the Bar Chart. Implemented in react/src/components/WeeklyColumnChart.tsx.

Default

Four weeks: the second has no data (a gap), the last is still running (hatched), then the one empty future week. Marker 1 is a change in the first week.

Rules

  • Chart Rule: there is always exactly one empty future week slot after the last week. todayAt draws a dotted Today line (--vs-chart-today) with a "Today" label; none when it is off the axis.
  • A week where no part has a value (null, negative or not a finite number) is a gap, never a 0 bar. A partial week (still running) is hatched.
  • Columns are scaled to the largest week total. Positions (todayAt, marker at) are in weeks from the left edge of the first column: 2.5 = the middle of the third week.
  • Markers on the axis get a dashed line and a numbered dot; close markers drop to a lower row (up to 3) so they never cover each other. A marker with no position, or outside the axis, is listed in the marker legend only. variant: 'unconfirmed' draws a hollow dashed dot.
  • Colours are tokens: series color, otherwise --vs-chart-series-1 to -3; grid --vs-chart-grid, axis --vs-chart-axis-text, dots --vs-color-brand-secondary. No animation.

Usage — React

import { WeeklyColumnChart } from '@vectorsticker/design-system'; <WeeklyColumnChart ariaLabel="Download links per week" series={[{ label: 'File on our site' }, { label: 'External link' }]} columns={[{ key: '2026-11-02', label: '2 Nov', values: [120, 40] }, { key: '2026-11-09', label: '9 Nov*', values: [30, 8], partial: true }]} todayAt={1.6} markers={[{ id: 1, label: 'New download page 3 Nov', at: 0.2 }]} />

Accessibility

The plot is role="img" with your ariaLabel; put the main numbers in it, or in a nearby table. The series and marker legends are real text; the dots on the axis are aria-hidden because the marker legend repeats them.
