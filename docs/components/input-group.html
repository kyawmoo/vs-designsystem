Input Group

A text field with a button docked inside its right edge — copy links, password-visibility toggles. Implemented in react/src/components/InputGroup.tsx and blade/components/vs-input-group.blade.php.

01 // Live

Example

140px right padding clears the button.

The button's click behavior (copy-to-clipboard, password toggle) is page-specific — not built into the component. React takes a plain onButtonClick handler; Blade takes a plain onclick string, or edit the component file directly for Alpine/Livewire wiring (x-on:click, wire:click aren't plain string attributes).

Usage — React

import { InputGroup } from '@vectorsticker/design-system'; <InputGroup value={referralLink} onButtonClick={copyLink}>Copy</InputGroup>

Usage — Blade

<x-vs-input-group :value="$link" readonly onclick="copyLink()"> <i class="fa fa-copy"></i> Copy </x-vs-input-group>
