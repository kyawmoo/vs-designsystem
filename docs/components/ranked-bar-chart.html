Ranked Bar Chart

One horizontal bar per label (a country, a category), the value written just past each bar's end (issue #144). React only; Chart.js. For values over time use the Bar Chart. Implemented in react/src/components/RankedBarChart.tsx.

Default

The examples on this page are static drawings of the same layout (the real chart is drawn on a canvas).

Thailand1,200
India860
Brazil370

Rules

  • The chart grows with the number of rows (rowHeight, default 34px) and is never shorter than minHeight (240px).
  • Long names are shortened with "…" (a trailing "(TH)" part is dropped first); the hover text has the full name.
  • No rows draws the empty text instead of a chart. A negative or non-finite value counts as 0 (no bar, no NaN).
  • Colours are tokens: bars --vs-chart-series-1 (or your color), grid --vs-chart-grid, axis --vs-chart-axis-text, text --vs-color-text-body. Reduced motion draws it without animation.

Usage — React

import { RankedBarChart } from '@vectorsticker/design-system'; <RankedBarChart ariaLabel="Downloads by country" valueLabel="Downloads" rows={[{ label: 'Thailand (TH)', value: 1200 }, { label: 'India (IN)', value: 860 }]} />

Accessibility

The canvas is role="img" with your ariaLabel; the values are only drawn on it, so put the same numbers in a nearby list or table when they matter (the Downloads page has one). Name and value text use --vs-color-text-body.
