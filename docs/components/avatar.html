Avatar

Person image with an initials fallback. Implemented in react/src/components/Avatar.tsx and blade/components/vs-avatar.blade.php (wraps the site's .user-avatar).

Sizes

Photo avatar at the four sizes. md / lg / xl are the live site's .user-avatar sizes (50 / 72 / 95px, 8px radius); sm (32px) is for compact bars.

Initials fallback (React)

Shown when there is no image or it fails to load. Initials sit on the brand green with --vs-color-text-on-primary (6.79:1); white would be 2.78:1 and fails WCAG AA.

AL AL AL AL

Shapes (React)

AL AL

rounded (default) is the live site's look; circle is fully round, as in the reports sidebar.

Usage — React

import { Avatar } from '@vectorsticker/design-system'; <Avatar src={user.avatarUrl} name="Ann Lee" size="lg" /> <Avatar name="Ann Lee" shape="circle" />

Usage — Blade

<x-vs-avatar :src="$user->getAvatar()" :name="$user->username" size="xl" :href="$user->getProfileLink()" class="me-0" />

Wraps the real .user-avatar / .user-avatar-lg / .user-avatar-xl classes, so it looks exactly like the current markup (used in 13 places across 12 views). It has no initials fallback and no sm size: those are React-only.

Accessibility

The wrapper is role="img" labelled with the name and the inner image has an empty alt, so a screen reader says the name once. A broken image switches to the initials automatically (React).
