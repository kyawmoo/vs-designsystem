List Row

One tappable row: an icon tile or avatar, a title, a one-line description, an optional badge and value, and a chevron (issue #71). React only. Moved from the reports site's approved stand-in (spike #67, decision (b)). Implemented in react/src/components/ListRow.tsx.

Default

FeedbackWhat visitors tell us about the site and the downloads›
Server HealthCPU, memory and disk of the server›
Sign out

Rules

  • With href the row is a link; otherwise a button that calls onClick. At least 60px high; the focus ring is --vs-focus-ring-color.
  • The icon sits in a 40px tile (--vs-color-lavender-surface, icon --vs-color-badge-free) and is hidden from screen readers; avatar replaces the tile.
  • The description is one line; a long one ends with "…" and never pushes the chevron out.
  • Rows one after another get a --vs-color-border line between them (none above the first). danger makes the icon and title red (--vs-color-danger-*).

Usage — React

import { ListRow } from '@vectorsticker/design-system'; <ListRow icon={<MessageSquare />} title="Feedback" description="What visitors tell us" onClick={open} /> <ListRow icon={<LogOut />} title="Sign out" danger chevron={false} onClick={logout} />
