02 // Correction

Audit note

The first draft of this component guessed wrong — caught before commit.

The first pass of this component used light pastel tint backgrounds with dark text, without re-reading the real vironeer-toastr.min.css file first. Re-auditing it directly found the real toasts are solid brand-colored fills (#8bc34a / #f44336 / #f6b800 / #00bcd4) with white text and a circular icon badge — the opposite of the first guess. Fixed before this ever shipped, per the audit-before-code rule adopted after the Button radius bug.

03 // Platform

React vs. Blade

Blade already has a full, working system — nothing to wrap.

Blade/Livewire toasts are entirely event-driven: a Livewire component calls $this->toastr('success', 'Saved!') (from the existing LivewireToastr trait), which dispatches a browser event that the vendored vironeer-toastr JS listens for and renders — there's no static markup to wrap, the same reason a Blade table wrapper was skipped for DataTables. Use the existing trait directly on Blade pages. React has no such library, so <Toast> is a real, presentational component — pair it with your own toast-stack state.
