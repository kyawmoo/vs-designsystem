Meter

A thin horizontal bar for a share, a progress or a usage value, with optional tick marks for limits. Added 23 Nov 2026 (issue #25), React only. Implemented in react/src/components/Meter.tsx.

Tones

Default 39%

Success 62%

Warning 78%

Danger 95%

Neutral 30%

Threshold ticks

Ticks sit on the same 0 to max scale as the value (here the Warning limit at 70 and the Danger limit at 90). They are decorative; the reading and its level are in valueText.

CPU 45% — Normal

Memory 78% — Warning

Disk 95% — Danger

Edge cases

0% is a reading

No reading (null)

120% is capped at 100%

-5 is clamped to empty

No reading draws an empty track with no fill element, never a 0% fill, and says "No reading". A value outside 0 to max keeps the bar inside the track, aria-valuenow inside the range, and the real reading in aria-valuetext ("120%"). An invalid max (0, negative, not a number) falls back to 100.

Usage — React

import { Meter } from '@vectorsticker/design-system'; <Meter label="Memory" value={78} tone="warning" thresholds={[{ value: 70, tone: 'warning' }, { value: 90, tone: 'danger' }]} valueText="78.0% — Warning" />

The plain status colours would be too weak on the grey track: the warning yellow is 1.19:1 and the success green 2.27:1 (WCAG 1.4.11 needs 3:1), so the fills are darkened and scripts/check-tokens.mjs keeps every fill at 3:1 or more. The warning fill therefore looks olive rather than bright yellow. A product with its own status colours (the reports dashboard's --vs-alert-*) overrides the --vs-meter-fill-* tokens.

Accessibility

role="meter" with aria-label, aria-valuemin="0", aria-valuemax, aria-valuenow and aria-valuetext. With no reading there is no aria-valuenow and the text is "No reading". Meaning is never only the colour: give the level in valueText and show the number as text next to the bar. For a list of rows whose text already says the value, use BreakdownList, which hides its bars from screen readers.
