Components // Popover

Popover

A panel that opens under a button, for content too big for a tooltip and too small for a Modal, for example a calendar. On a phone it becomes a bottom sheet. Implemented in react/src/components/Popover.tsx (React only; no Blade version).

01 // Live

Example

Click the button. Escape or a click outside closes it; focus goes in and comes back.

Any content The panel lines up with the right edge of the button (align="end", the default).
02 // Phone

On a phone

Under 768px (sheetBelow, same as FilterSheet) the panel is a bottom sheet with a backdrop; the page behind does not scroll.

Any contentTap the backdrop or press Escape to close.
03 // Behaviour

Behaviour

What the component does for you.

SituationWhat happens
OpenFocus moves to the first control inside (or the panel itself). Tab and Shift+Tab stay inside the panel.
Escape / click outsideonClose is called. A click on the anchor is not "outside": the anchor's own click should toggle open.
CloseFocus returns to the anchor, unless the viewer clicked another control (it keeps the focus).
PositionUnder the anchor (above it when there is no room), lined up with its right edge (align="end") or left edge ("start"), always inside the viewport; re-placed on scroll and resize.
ClippingDrawn in a portal (document.body), so a card's overflow: hidden cannot cut it off. z-index: 60, above Modal, Drawer and FilterSheet (50).
PhoneBottom sheet with a backdrop, aria-modal="true", page scroll locked while open.
Reduced motionNo slide or fade.

05 // Guidelines

Do’s and Don’ts

Short rules.

DOUse it for a small interactive panel that belongs to one button (a calendar, a few options).
<Popover anchorRef={ref} …>
DON’TDon’t use it for a short hint on hover. That is a Tooltip.
Tooltip
DOGive it a name (label) and let the anchor toggle open.
aria-haspopup="dialog" aria-expanded={open}
DON’TDon’t use it for a task that needs the whole page. That is a Modal or a Drawer.
Modal · Drawer

Usage — React

import { Popover } from '@vectorsticker/design-system'; const ref = useRef<HTMLButtonElement>(null); const [open, setOpen] = useState(false); <button ref={ref} aria-haspopup="dialog" aria-expanded={open} onClick={() => setOpen((o) => !o)}>Open</button> <Popover open={open} onClose={() => setOpen(false)} anchorRef={ref} label="Pick a range"> …content… </Popover>
