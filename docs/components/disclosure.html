Disclosure

A card whose header (icon tile, title, description, chevron) opens and closes its body (issue #70). React only. Moved from the reports site's approved stand-in (spike #67, decision (b)). Implemented in react/src/components/Disclosure.tsx.

Default

Tap a header to open or close it (this preview is plain HTML with the same structure).

Rules

  • A native <details>/<summary>: click, Enter and Space open and close it without a script, and each Disclosure opens on its own. The header also carries aria-expanded.
  • defaultOpen draws it open. The chevron turns 180° when open (200ms; not with reduced motion).
  • Card: --vs-color-surface, 1px --vs-color-border, --vs-card-radius (8px), 20px below 1024px (--vs-card-radius-lg, as the other cards, #156). The header is at least 60px; the icon tile and chevron are hidden from screen readers.

Usage — React

import { Disclosure } from '@vectorsticker/design-system'; <Disclosure icon={<PieChart />} title="Traffic Sources" description="Last 30 days" defaultOpen> … </Disclosure>
