Text Effects

Effects that give text some life: a title that is written letter by letter, a number that counts up. Every effect has a React component and a Blade component, plain text when it does not play, and reduced motion switches it off. A new effect is added to this page.

Effects

  • Title wipe (RevealText): the page title appears letter by letter after the page opening.
  • Number count-up (AnimatedNumber): a figure counts up to its value.

Title wipe: RevealText

A page title that appears letter by letter from the left, each letter rising from below its line and coming into focus (the "Welcome back" style). It belongs to the page opening (Reveal): put it inside the page body, and it starts together with the body fade, after the curtain. It is the element itself (as, for example h1).

Title wipe (here without the curtain, so it starts at once)

PropValues
textThe title. It is turned into letters only while the opening plays; with play off or on a later mount (React), or with :play="false" on the parent (Blade), it is plain text and no extra element.
asReact: any element, default span. Blade: span (default), div, p, h1 to h6; any other value falls back to span.
othersPassed to the element (className / class, id, aria-*).
  • Timing (tokens): a letter takes --vs-motion-text-duration (420ms) and starts --vs-motion-text-stagger (35ms) after the one before it. The first letter starts with the body (curtain + --vs-motion-delay-body). Focus comes sooner than the rise (65% of the time), so only the last letters at the edge are blurred while the earlier ones are still climbing.
  • The numbers. 0.85em rise, 60% start size, 8px blur and the 65% are an Estimate read from the frames of the reference recording, not measured exactly.
  • Wrapping. Words stay together; the title wraps at the spaces. Letters are grapheme clusters, so a letter with combining marks (Burmese) is never cut in two. The letters after the 30th start together with it, so a long title never waits for seconds.
  • Plays once. A CSS animation plays again for an element that is inserted again. Use it for a title that mounts with the page, and show plain text when the same title mounts later (back from another tab).
  • Accessibility. Screen readers read a visually hidden copy of the real text once; the letters are aria-hidden. With reduced motion, or JavaScript off, the text is simply visible.
  • Layout. Letters are inline-block, so the kerning between letters is lost; the prototype measured a title 101.9px wide against 102.0px as plain text.

Number count-up: AnimatedNumber

A figure that counts up from the number last shown (from 0 at first) with an ease-out curve, for KPI cards or any headline number. It ends on exactly the value: the last frame is formatted by format with the value itself, so what stays on screen is written as it would be without the animation.

  • Final figure. React: the last frame passes value itself to format (12.35 with toFixed(1) stays "12.3", it is not rounded to the steps first). Blade: at the end the script puts the server's text back, character for character. PHP's number_format rounds half up and JavaScript's toFixed works on the binary value, so the two can differ in the last digit for a value like 12.35 with one decimal; pass a value with the decimals you show.
  • Accessibility. Screen readers read a visually hidden copy of the final figure once; the moving text is aria-hidden (an aria-label on a plain span is not allowed and many screen readers ignore it, so it is not used). Reduced motion shows the final figure only.
  • JavaScript off (Blade). The page shows the final figure; the count is a progressive enhancement. Below the fold the figure shows 0 until it is scrolled into view; elements added later: call VsAnimatedNumber.init(container).

Adding an effect

This page is where text effects live. To add one, add a section here and give it everything on this list, so the next person can take it without asking:

  1. A React component and a Blade component (x-vs-...) with the same props, in react/src/components/ and blade/components/.
  2. Its timing in --vs-motion-* tokens (tokens.css, tokens.json, the docs copy), no raw colour.
  3. Plain text, no extra elements, when it does not play; a screen reader reads the real text once.
  4. prefers-reduced-motion: reduce shows the final state; JavaScript off shows the final state.
  5. Unit tests (normal and failure cases) and a real-browser check in react/browser/reveal-check.mjs, run in Chromium, WebKit and Firefox by CI.
  6. A live demo with a Replay button, usage for React and Blade, a props table and the rules, in a section of this page; a line in the list at the top.
