Card

A generic content container. Implemented in react/src/components/Card.tsx and blade/components/vs-card.blade.php — the two are not visually identical, and that's intentional; see below.

01 // Platform Difference

Blade <x-vs-card>borderless

.card-v, app.css

The real .card-v class (audited directly from public/themes/basic/assets/css/app.css) has no border — it sits on the public site's white page background, so padding and radius alone read as a card. The dashboard's own cards (SummaryCard, TableWidget) always use a 1px border, because they sit on the report site's gray canvas and need a visible edge. React's <Card> follows that existing dashboard convention rather than copying .card-v literally — copying it border-less would make cards invisible against the report site's own gray background. Blade's <x-vs-card> wraps the real class as-is, borderless, matching the public site exactly.
