Rating

Display-only star rating, Blade only. Implemented in blade/components/vs-rating.blade.php (wraps the site's rating-stars markup).

Values

Display-only stars. A star is filled when value is greater than its position, the same rule as the site's rating-stars partial.

The colours above are only this page's illustration: the real filled/empty colours come from the site's own .rating / .rating-active CSS, which the Blade component keeps.

Usage — Blade

<x-vs-rating :value="$item->avg_rating" :label="translate('Rated :n out of 5', ['n' => $item->avg_rating])" class="mb-2" />

Same markup and classes as resources/views/themes/basic/partials/rating-stars.blade.php (included 13+ times in 8 views), so it looks the same. It adds the accessible name the partial lacks: the wrapper is role="img" with a label and the stars are hidden from screen readers. Pass a translated label; the English default is "Rated {value} out of {max}".

React: not built. The reports dashboard shows no star ratings; build it when a real use appears.
