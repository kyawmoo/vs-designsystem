Bootstrap 5.3 draws it at width: 2em; height: 1em — 32 × 16px with a 12px knob at the default 16px font size, matching the measurement guide above. The unfocused-off colour #AAAAAA is from .form-switch .form-check-input:not(:checked):focus in app.css.

06 // Guidelines

Do’s and Don’ts

$switch-guidelines

DOUse a switch for on/off settings that apply immediately.
DON’TDon’t use a switch when a separate Save is needed — use a checkbox instead.
DOSay clearly what “on” means.
DON’TDon’t leave the state ambiguous without a label.

Usage — React

import { Switch } from '@vectorsticker/design-system'; <Switch name="notifications" defaultChecked>Email notifications</Switch>

Usage — Blade
