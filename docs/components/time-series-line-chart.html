Time Series Line Chart

A time-series line with dotted Warning and Danger lines, gaps for missing readings, spike markers, a "Highest" ring and an optional "Now" space (issue #13). React only; Chart.js. Moved from the reports site's Server Health chart (decision 2a). Implemented in react/src/components/TimeSeriesLineChart.tsx.

Rules

  • A null reading is a gap in the line, never 0. Segments are straight. A reading with no neighbour is drawn as a dot so it is never invisible.
  • thresholds draws dotted Warning and Danger lines; a stretch that reaches one (judged on maxPoints when given) is drawn in its colour.
  • Markers: shape = severity (Warning triangle, Danger ⚠ sign), colour or tick = status (new, investigating dulled, resolved green tick, ignored small grey dot); urgent ones are drawn on top. peakStyle="pin" puts a dot at the peak with a dotted drop to the line.
  • futureMs adds empty space after to with a dotted "Now" line (Chart Rule). tickStep="day": one tick per local day, today bold with "(Today)"; narrow charts show the day number.
  • Click a marker: onSelectMarker(id). Click empty plot: onZoomAt(t) (magnifier cursor). Tooltips say severity, status and value in words.
  • Colours: any CSS colour or var(--token) through colors, read at draw time. Defaults: line --vs-color-brand-primary, warning --vs-color-warning-border, danger --vs-color-danger-border, grid --vs-color-border. Animates the first drawing and new data only; never with reduced motion.
  • Pass points, thresholds, markers and colors as stable values (e.g. useMemo): a new object on each render rebuilds the chart.

Usage — React

import { TimeSeriesLineChart } from '@vectorsticker/design-system'; <TimeSeriesLineChart ariaLabel="CPU usage, last 24 hours" seriesLabel="CPU" points={points} thresholds={{ warning: 70, danger: 90 }} markers={markers} from={from} to={now} days={1} futureMs={2 * 3600_000} yMax={100} formatValue={(v) => `${v.toFixed(1)}%`} onSelectMarker={openEvent} />
