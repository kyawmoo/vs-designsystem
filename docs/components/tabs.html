03 // Platform Difference

React vs. Blade

Deliberately not unified — both are real, both already ship.

React (vs-segment-control / vs-segment-button) is a single bordered track with a solid brand-primary fill on the active tab — this is already live in the reports dashboard's TableWidget and several views, so the <Tabs> component formalizes it, not invents it. Blade (.tabs-custom .nav-pills) is individually bordered pills with gaps between them, no shared track — this is the main site's own existing CSS, already correct and in production.

These were audited side by side and found visually different. Per this system's "change the component, not the page" principle, neither was forced to match the other — that would mean changing pages that already work correctly today. Each wrapper simply reuses its platform's real, proven pattern.

Usage — React

import { Tabs } from '@vectorsticker/design-system'; <Tabs tabs={[{ id: 'overview', label: 'Overview' }, { id: 'items', label: 'Items' }]} activeId={activeId} onChange={setActiveId} />

Usage — Blade

<x-vs-tabs :tabs="[['id' => 'overview', 'label' => 'Overview'], ['id' => 'items', 'label' => 'Items']]" :activeId="'overview'" /> <!-- pair with Bootstrap's data-bs-toggle="pill" tab-content panes -->
