Mobile Page Header

The phone page header (hidden from 768px up): the page title, a back button on pages opened from a menu or a list, and an optional control and filter button on the same row. React only. From the approved phone canvas (issue #145, decision 1a). Implemented in react/src/components/MobilePageHeader.tsx.

Rules

  • Tab pages (showBack={false}): a 28px title. Pages opened from a menu or a list: a round 44px back button and a 20px title. Long titles end with "…".
  • The back button goes back in the browser history; onBack replaces that (e.g. a full-screen panel passes its close).
  • The filter button is round, 44px; when filterActive it is dark (--vs-color-brand-secondary) and has aria-pressed="true". filterIcon: calendar for a day-range picker, sliders otherwise.
  • trailing (e.g. a DateRangeSelector) sits after the title, before the filter button. The whole header is hidden from 768px up.

Usage — React

import { MobilePageHeader } from '@vectorsticker/design-system'; <MobilePageHeader title="Server Health" onFilterClick={openSheet} filterActive={days !== 7} /> <MobilePageHeader title="Event details" onBack={closePanel} />
