Components // Drawer

Drawer

A full-height panel that slides in from the right edge over a dimmed overlay — for the details of one row (a user, an event) without leaving the page. Same overlay and close button as Modal.

01 // Live

Example

Open it, then close with ✕, Escape or a click on the dimmed area.

02 // Anatomy

Anatomy

Header (title or custom header + close), scrolling body, optional fixed footer.

Header

✕
Body — scrolls on its own when the content is long.
Footer — stays at the bottom (e.g. pagination)
03 // When to use

Drawer or Modal?

Drawer — details or a long list about one row, read next to the page it came from (a user's downloaded images, an event's history). Modal — a short, focused task or message (reset a password, confirm a delete).

05 // Accessibility

Behaviour

ActionResult
OpenFocus moves to the close button; the page behind stops scrolling
Tab / Shift+TabStays inside the panel (wraps around)
Escape, ✕, click on the overlayCalls onClose
CloseFocus returns to the element that opened it; page scroll restored
Screen readersrole="dialog", aria-modal="true", named by title (also when a custom header is shown)
