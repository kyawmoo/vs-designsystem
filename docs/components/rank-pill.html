Rank Pill

The position of an item in a ranking: "#2" or "#1 · Top asset". An inline element; you place it (for example over the corner of a picture). Added 23 Nov 2026, React only. Implemented in react/src/components/RankPill.tsx.

Pill

Rank 1 is lime with dark text by default; every other rank is dark with white text. A label is written after the number.

#1 · Top asset#1#2#3#12

Tones

#4#4#4

Circle

shape="circle" shows the number alone, as in the vectorsticker.com podium. The label is not written, but a screen reader still hears it.

Usage — React

import { RankPill } from '@vectorsticker/design-system'; <RankPill rank={1} label="Top asset" /> <RankPill rank={3} shape="circle" />

Accessibility

The visible text ("#1 · Top asset") is hidden from screen readers and replaced by "Rank 1, Top asset", so the symbols are not read out. Every text on its fill is at 4.5:1 or more (dark on lime 13.0, white on dark 15.9, dark on white 15.9), kept by scripts/check-tokens.mjs. Colours come from existing tokens (--vs-color-brand-accent, --vs-color-brand-secondary, --vs-color-surface); no new token.
