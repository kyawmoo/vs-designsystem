Components // Bar Chart

Bar Chart

Daily bars on Chart.js with the same chart rules as Line Chart (one column per day, today marked, one empty day after today, missing days left empty). Bars grow in from left to right; parts of a total can be stacked with the day total on top, and a line can be drawn over the bars.

02 // When to use

Bar or Line?

Bar Chart — counts per day, especially parts of a total (free + premium, Google + Facebook + Email). Line Chart — a smooth trend over time where the shape matters more than each day's count.

03 // Behaviour

Details

PartBehaviour
Bar styleSlim bars with 6px rounded tops and a soft top-to-bottom gradient. Up to 10 days: wide bars with no width cap; more days: bars up to 28px wide. Hovering a day fades the other days
Stacked columnsRounded corners only on the top part; tooltip footer shows the day total
Value labelsStacked: the day total above each column. Not stacked: each value above its bar or point. Shown only while every label fits its column; a label that would overlap another is left out
Line seriesDrawn over the bars with a soft area, draws left to right; usually on the right axis
AnimationBars grow from the bottom, one day after another (900ms in total); none with reduced motion
ColoursSame --vs-chart-* tokens as Line Chart

Usage — React

import { BarChart } from '@vectorsticker/design-system'; <BarChart stacked showValues ariaLabel="Daily downloads" dates={dates} series={[ { id: 'free', label: 'Free downloads', data: free }, { id: 'premium', label: 'Premium downloads', data: premium }, ]} />
