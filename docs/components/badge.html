Badge

Three tone families, one component: semantic, product, and item-status (admin moderation). Implemented in react/src/components/Badge.tsx and blade/components/vs-badge.blade.php + vs-item-badge.blade.php.

Semantic

Success Warning Danger Info Neutral

Product (item card)

Trending On Sale Free Premium

Item status (admin moderation)

Pending Soft Rejected Resubmitted Approved Hard Rejected Deleted

On Blade, item-status badges are solid (bg-orange etc, matching the real admin table). On React, they use the same 12%-tint pattern as semantic/product badges via color-mix(), since no dedicated tint token exists for them.

Dot variant

React only — a leading solid dot instead of a filled background, for denser contexts.

Online Offline

Usage — React

import { Badge } from '@vectorsticker/design-system'; <Badge tone="success">Verified</Badge> <Badge tone="trending">Trending</Badge> <Badge tone="approved" dot>Approved</Badge>

Usage — Blade

<!-- item-status --> <x-vs-badge item-status="pending">{{ $item->getStatusName() }}</x-vs-badge> <!-- generic --> <x-vs-badge tone="success">Verified</x-vs-badge> <!-- item card product badge --> <x-vs-item-badge type="premium" />
