The reports dashboard's search + sort bar — formalizes a pattern already duplicated identically across the Items and Category views into one reusable component.

02 // Platform

React only

No Blade counterpart — and that's intentional.

This bar is the reports dashboard's own convention — it isn't derived from any real vectorsticker.com page, so there's nothing on the main site to wrap. Same treatment as SummaryCard, TableWidget, and FilterSheet: dashboard-only, React-only.

Usage — React

import { FilterBar } from '@vectorsticker/design-system'; <FilterBar searchValue={search} onSearchChange={setSearch} searchPlaceholder="Search sticker name, slug, or category..." tabs={[{ id: 'views', label: 'Most Viewed' }, { id: 'downloads', label: 'Most Downloaded' }]} activeTabId={filterType} onTabChange={setFilterType} />

PropRequiredValues
