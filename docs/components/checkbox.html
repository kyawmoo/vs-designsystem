05 // Guidelines

Do’s and Don’ts

$checkbox-guidelines

DOAlways pair a checkbox with a clickable label.
DON’TDon’t leave a checkbox with no label — its purpose is unclear.
DOGroup related checkboxes together.
DON’TDon’t scatter related options across the page.
