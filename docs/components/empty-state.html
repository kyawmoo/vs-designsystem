Empty State

"Nothing to show here" message with an optional description and action. Implemented in react/src/components/EmptyState.tsx and blade/components/vs-empty-state.blade.php (wraps the site's .dashboard-card-empty).

Default

No downloads yet

Downloads show up here after the first visitor saves a sticker.

Compact, title only

No followers found

Usage — React

import { EmptyState, Button } from '@vectorsticker/design-system'; <EmptyState title="No downloads yet" description="Downloads show up here after the first save." action={<Button emphasis="tertiary">Reset filters</Button>} />

Usage — Blade

<x-vs-empty-state :title="translate('No data found')" size="lg"> <x-slot:icon><!-- optional illustration --></x-slot:icon> </x-vs-empty-state>

Wraps the real .dashboard-card-empty class (size="lg" adds .pd, 8rem top and bottom). Same markup as the workspace card-empty partial, so it can replace that partial and the 12 copies of <div class="dashboard-card-empty pd">.

Accessibility

The block is role="status", so a list that becomes empty is announced politely. The title and description use the heading and body text colours; the muted grey (--vs-color-text-muted, about 2.8:1 on white) is used only for the decorative icon. The live site's current block uses .text-muted for all text.
