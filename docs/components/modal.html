Modal

An overlay + centered panel shell, formalized from the reports dashboard's own ForgotPasswordModal — the only real modal already live. Content is passed as children; this component owns only the shell.

02 // Platform

React vs. Blade

React owns the overlay/animation; Blade reuses Bootstrap's own.

React renders its own overlay + panel, since the reports dashboard has no Bootstrap JS loaded. Blade wraps Bootstrap's real .modal/.modal-dialog/ .modal-content markup — already styled by the vendored bootstrap.min.css, and already wired for open/close by Bootstrap's own bundled JS via data-bs-toggle/data-bs-dismiss, so no new JS was written for it — same reasoning as vs-pagination.blade.php wrapping Laravel's own paginator view.

Usage — React

import { Modal } from '@vectorsticker/design-system'; <Modal open={open} onClose={() => setOpen(false)} title="Reset your password"> <p>Enter your account email...</p> </Modal>

Usage — Blade

<x-vs-modal id="resetModal" title="Reset your password"> Enter your account email... <x-slot:footer> <button class="btn btn-primary">Send Link</button> </x-slot:footer> </x-vs-modal> <!-- trigger: <button data-bs-toggle="modal" data-bs-target="#resetModal"> -->
