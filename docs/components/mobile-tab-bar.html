Mobile Tab Bar

The phone bottom navigation: a dark pill with icon + label items; one accent pill slides to the selected item (issue #68). React only. Moved from the reports site's approved stand-in (spike #67, decision (b)). Implemented in react/src/components/MobileTabBar.tsx.

Default

A static drawing of the bar (the real one slides its pill to the tapped item).

OverviewItemsUsersMore

Rules

  • Designed for up to 5 items. Each item is an icon and a short label; an item with href is a link, otherwise a button.
  • The selected item has aria-current="page" and --vs-color-text-on-primary text on the --vs-color-brand-accent pill; the others are --vs-color-text-muted on --vs-color-brand-secondary. The pill is fully round on the first and last item, 12px corners between. It slides in 300ms; not with reduced motion.
  • Every item is at least 44 × 52 px and shows the focus ring --vs-focus-ring-color-on-dark.
  • MobileTabBarDock fixes the bar to the bottom: 12px at the sides, at least 20px below, more where the home indicator needs it (env(safe-area-inset-bottom)).
  • No items: an empty navigation landmark. An unknown activeId: nothing selected, no pill.

Usage — React

import { MobileTabBar, MobileTabBarDock } from '@vectorsticker/design-system'; <MobileTabBarDock className="lg:hidden"> <MobileTabBar items={[{ id: 'overview', label: 'Overview', icon: Home }, { id: 'more', label: 'More', icon: MoreHorizontal }]} activeId="overview" onSelect={setTab} /> </MobileTabBarDock>
