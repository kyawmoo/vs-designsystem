Rewind Reveal

A timeline fills in newest first. Today appears at once, then the days before it follow, one after the other, each a little later than the one before. Days after today are not animated. The animation is plain CSS (the vs-rewind block in react/src/styles.css and blade/components.css, kept equal by check-tokens), timed by the --vs-motion-rewind-* tokens. Made for the days of a calendar; it works for any list that has a date.

Demo

Today is fixed to 12 Nov 2026 in the demo so it always looks the same. Press Replay to see it again.

The order

ItemStep
Today0 (starts at once)
Days before today1, 2, 3 ... newest first. Each step starts --vs-motion-rewind-step after the one before it.
Days after todayNo step: shown at once, no animation.
Many daysSteps stop at maxSteps (default 18, at most 60): older days share the last step, so a long list never makes the viewer wait. With the default tokens the whole effect takes about 0.9 s (18 x 30 ms + 360 ms).

A day is the text 'YYYY-MM-DD' (a calendar date, no time zone). The steps count only the days you pass in, so pass the days that should animate (all cells, or only the cells that hold something). Values that are not real days (2026-02-30, abc) are skipped. A today that is not a real day throws RangeError: guessing a today would animate the wrong days.

Usage: plain HTML and JavaScript (no framework)

<!-- load the CSS (blade/components.css) and the script once --> <script src="/path/to/rewind-reveal.js"></script> <!-- each day cell carries its date; the cell itself, not a wrapper --> <div id="month"> <div data-vs-rewind-day="2026-11-12">12</div> <div data-vs-rewind-day="2026-11-11">11</div> … </div> // after the cells are drawn, and again after every redraw (a new month) VsRewind.apply(document.getElementById('month'), '2026-11-12', { maxSteps: 18 });

VsRewind.apply(container, todayKey, options?) sets data-vs-rewind and --vs-rewind-i on the cells that take part, takes them off the others, and returns how many take part. Calling it again plays the effect again. VsRewind.clear(container) takes the animation off. VsRewind.indexByDay(days, todayKey, maxSteps?) returns the step of each day as { 'YYYY-MM-DD': step } if you want to set the attribute yourself.

Usage: React

import { RewindItem, rewindIndexes } from '@vectorsticker/design-system'; const steps = rewindIndexes(days, todayKey); // Map<'YYYY-MM-DD', step> <div key={monthKey}> {/* a new key mounts the days again: the effect plays again */} {days.map((d) => ( <RewindItem key={d} index={steps.get(d)} className="day">…</RewindItem> ))} </div>
NameProp / argumentValues
RewindItemindexThe step. 0 starts at once. null, undefined, a negative or a non-number: no animation, shown at once. A fraction is rounded down; the most is 60.
RewindItemasThe element to render, default div. The item is this element, not a wrapper around it.
RewindItemothersPassed to the element (className, style, aria-*, …).
rewindIndexes(days, today, maxSteps?)Returns a Map from day to step, by the order above. Throws RangeError for a bad today.

Rules

  • Content is never hidden by a base rule. The hidden state exists only inside the keyframes, so with the animation switched off the content is simply visible.
  • Reduced motion. With prefers-reduced-motion: reduce nothing animates and every day is shown at once.
  • Keyboard. The waiting state is also visibility: hidden (first keyframe only), so a day that is not shown yet cannot take focus.
  • No double fade. An item inside another animated item does not animate by itself.
  • Only opacity and transform move (the rise is half of --vs-motion-rise-distance), so the layout never shifts.
  • It plays when the element is inserted. To play it again, draw the cells again and call apply (plain HTML), or mount the items again (React).
  • Keep it for the first view of a screen. Do not use it on a list that updates often (live data): every redraw would play it again.

Tokens

TokenDefaultUse
--vs-motion-rewind-duration360msHow long one day takes to fade in and rise.
--vs-motion-rewind-step30msHow much later each step starts.
--vs-motion-ease-deceleratecubic-bezier(0.2, 0, 0, 1)The easing (shared with Reveal).
--vs-motion-rise-distance14pxThe rise is half of this (shared with Reveal).

The default times are an Estimate taken from the frames of a reference recording and chosen for this design; they were not tested with users.
