Stacked Bar

One horizontal bar made of the parts of one whole (file vs. external link, guest / member / subscriber), with a swatch legend (issue #151). React only; plain HTML, no chart library. For one value use the Meter, for rows the Breakdown List. Implemented in react/src/components/StackedBar.tsx.

Default

  • File 75%
  • External link 25%

Rules

  • Each segment is as wide as its share of the total, so the parts always fill the track exactly (never wider, whatever the values add up to).
  • A part with 0 (or a negative / non-finite value) gets no segment but stays in the legend as 0%. A share above 0 and below 1% is written <1%; others are rounded.
  • No parts, or every value 0: the empty text instead of the bar.
  • Colours are tokens: a part's color, otherwise --vs-chart-donut-1 to -6 in order (the same palette as the Donut Chart). Track --vs-color-border, legend text --vs-color-text-body / --vs-color-text-heading.

Usage — React

import { StackedBar } from '@vectorsticker/design-system'; <StackedBar ariaLabel="Downloads by type: File 75%, External link 25%" parts={[{ key: 'file', label: 'File', value: 300 }, { key: 'link', label: 'External link', value: 100 }]} />

Accessibility

The bar is role="img" with your ariaLabel; the legend is real text (name and percentage), so the colour is never the only signal. Swatches are aria-hidden.
