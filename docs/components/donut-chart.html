Donut Chart

A ring of segments with a total in the middle and a legend of swatch, name and percentage (issue #72). React only; plain SVG, no chart library. Added 23 Nov 2026. Implemented in react/src/components/DonutChart.tsx.

Empty, and one segment

9Total

No segments, or every value 0, draws the empty ring at the same size with the empty text in the middle (no NaN, no broken ring). A negative or non-finite value counts as 0 and is not drawn. One segment is a whole ring. A segment under 1% is still drawn and written "<1%".

Colours

Segments use these tokens in order and then repeat; a segment can bring its own color. Each is at least 3:1 on white, and the legend names every segment in text, so colour is never the only signal. More than six segments: group the small ones as "Other" before passing them in.

Motion

The ring draws in once, a segment after the other (about 0.8s in all). Under prefers-reduced-motion: reduce it does not move (scripts/check-tokens.mjs keeps that rule). The examples on this page are static.

Accessibility

The ring is role="img" with your ariaLabel. The middle text and the legend (swatch, name, percentage) are real text, so a screen reader reads them; the swatches are decorative. Each segment has a native hover text ("Direct: 4,742 (38%)"). Share text uses --vs-color-text-heading on white (14:1). The percentages are rounded, so they can add up to 99% or 101%. The neighbouring segments are separated by a small gap so similar colours stay apart.
