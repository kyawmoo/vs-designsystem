Summary Card Carousel

A row of KPI cards (SummaryCard): a grid from 768px, one swipeable row with dots below it. Moved here from the reports dashboard (27 Nov 2026), React only. Implemented in react/src/components/SummaryCardCarousel.tsx, on top of SwipeCarousel.

Grid (768px and up)

2 columns from 768px (shown here), 4 from 1024px. With exactly five cards, 5 columns from 1280px, so the fifth card is not alone on a second row. The gap is 1rem.

On a phone (under 768px)

One row that scrolls sideways and snaps to a card. Each card is 88% wide, so the next one peeks in. A dot per card; tapping a dot scrolls to that card. A single card shows no dots.

Notes

Both layouts are rendered and CSS shows one of them, so each card exists twice in the page (the same as SwipeCarousel). The swipe row hides its scrollbar with the site's no-scrollbar utility, which this package does not define. Utility classes in the component (md:grid, xl:grid-cols-5, w-[88%]) need the site's Tailwind to scan react/src, as it already does for SwipeCarousel.

It rests on SwipeCarousel, which got one optional prop for this, mobileClassName (default 'sm:hidden', so existing uses do not change): the swipe row must hide at the same breakpoint where the grid appears.
