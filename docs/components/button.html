Button

Primary / Secondary / Tertiary emphasis, in text-only, icon+text or icon-only form. Implemented in react/src/components/Button.tsx and blade/components/vs-button.blade.php.

Emphasis

EmphasisReact emphasisBlade variantReal class (Blade)
Primary"primary""primary".btn-primary
Secondary"secondary""secondary".btn-secondary
Tertiary"tertiary""tertiary".btn-soft

Size

Icon-only

Square, not a pill — var(--vs-radius-sm), sized off the shared icon scale (see Iconography).

On Blade, this replaces the ad-hoc inline style="height:38px;width:38px;padding:0;" hack seen in grid-buttons.blade.php — the sizes are now the same component-level fix on both platforms.

Usage — React

import { Button } from '@vectorsticker/design-system'; <Button emphasis="primary">Save changes</Button> <Button emphasis="tertiary" size="sm">Cancel</Button> <Button iconOnly icon={<Trash2 />} aria-label="Delete" />

Usage — Blade

<x-vs-button variant="primary">Save changes</x-vs-button> <x-vs-button variant="tertiary" size="sm">Cancel</x-vs-button> <x-vs-button variant="tertiary" icon-only aria-label="Delete"> <x-slot:icon><i class="fa-solid fa-trash"></i></x-slot:icon> </x-vs-button>
