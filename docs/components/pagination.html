02 // Platform Difference

React vs. Blade

Different data source, same visual output.

React takes plain page/ totalPages numbers and an onPageChange callback — the reports dashboard has no server-rendered paginator, so it computes its own windowed page range. Blade takes a real Laravel paginator instance (Model::paginate()) and simply renders $paginator->links() — Laravel's own pagination view already outputs the exact .page-item / .page-link markup the site's CSS styles correctly, so there was nothing to re-wrap.
