Components // Date Range Selector

Date Range Selector

Picks how many days a report page shows: Today, 3D, 7D, 90D. A compact segmented control on desktop; on a phone it is one button that opens a bottom sheet. Implemented in react/src/components/DateRangeSelector.tsx (React only; there is no Blade version).

01 // Live

Example

Click a range. The dates under the control are worked out from today (the page’s job, not the component’s).

02 // Phone

On a phone

Under 768px the buttons are replaced by one trigger (calendar icon, current range, chevron) and a bottom sheet. Same breakpoint as FilterSheet.

06 // Guidelines

Do’s and Don’ts

Short rules.

DOShow the real dates under the control (summary), so “7D” is never a guess.
26 Oct – 1 Nov 2026 · 7 days
DON’TDon’t use it for choosing between different content. That is Tabs.
DOGive every option a full label (fullLabel). Screen readers and the phone sheet use it.
{ id: '3d', label: '3D', fullLabel: '3 Days' }
DON’TDon’t add more than about 5 options. Use a date picker instead.

Not included (yet)

Custom date range: the calendar and its popover do not exist in this design system yet. This component has presets only. A custom range will be a separate component, added later without changing these props. Blade: there is no Blade version.

Usage — React

import { DateRangeSelector } from '@vectorsticker/design-system'; <DateRangeSelector value={range} // '7d' onChange={setRange} loading={isFetching} summary="26 Oct – 1 Nov 2026 · 7 days" /> // own list for a page that needs other presets: <DateRangeSelector options={[{ id: 'today', label: 'Today', fullLabel: 'Today' }, { id: '7d', label: '7D', fullLabel: '7 Days' }]} value={range} onChange={setRange} />
