Components // Date Range Selector

Date Range Selector

Picks how many days a report page shows: Today, 3D, 7D, 90D, and optionally a Custom date range. A compact segmented control on desktop; on a phone it is one button that opens a bottom sheet. Implemented in react/src/components/DateRangeSelector.tsx (React only; there is no Blade version).

01 // Live

Example

Click a range. The dates under the control are worked out from today (the page’s job, not the component’s).

02 // Phone

On a phone

Under 768px the buttons are replaced by one trigger (calendar icon, current range, chevron) and a bottom sheet. Same breakpoint as FilterSheet.

06 // Guidelines

Do’s and Don’ts

Short rules.

DOShow the real dates under the control (summary), so “7D” is never a guess.
26 Oct – 1 Nov 2026 · 7 days
DON’TDon’t use it for choosing between different content. That is Tabs.
DOGive every option a full label (fullLabel). Screen readers and the phone sheet use it.
{ id: '3d', label: '3D', fullLabel: '3 Days' }
DON’TDon’t add more than about 5 options. Use a date picker instead.

SituationWhat happens
OpenClick the calendar button. Both fields start empty, or with the applied range.
ApplyOff until both dates are picked. onCustomChange({ from, to }), then onChange('custom') (only if value is not already 'custom'); the picker closes and focus returns to the button.
Cancel / Escape / click outsideCloses; nothing is called; the next open starts from the applied range again.
LimitsminDate, maxDate (default today) and maxDays (default 365) go to the calendar; the help text under it says them in words.
PhoneThe sheet list gets a "Custom range…" row; picking it opens the picker as a bottom sheet with one month. The trigger shows the dates while custom is applied.
The page's jobKeep value ('custom' or a preset id) and customRange; turn the two dates into whatever the data needs.

Usage — React

import { DateRangeSelector } from '@vectorsticker/design-system'; <DateRangeSelector value={range} // '7d' onChange={setRange} loading={isFetching} summary="26 Oct – 1 Nov 2026 · 7 days" /> // with a custom range (value 'custom' + customRange): <DateRangeSelector allowCustom value={range} onChange={setRange} customRange={custom} onCustomChange={setCustom} maxDays={92} /> // own list for a page that needs other presets: <DateRangeSelector options={[{ id: 'today', label: 'Today', fullLabel: 'Today' }, { id: '7d', label: '7D', fullLabel: '7 Days' }]} value={range} onChange={setRange} />
