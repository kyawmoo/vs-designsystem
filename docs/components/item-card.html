Two deliberate differences from the spec drawing. (1) Badge text: the spec shows white on every badge, but white is 2.78:1 on the premium green and 2.4:1 on the sale teal (WCAG AA needs 4.5:1), so those two use the dark on-primary text; npm run check:tokens gates all four. (2) Sale price uses --vs-color-brand-primary-text (about 5.3:1) instead of the plain green --vs-card-price-sale-color (2.78:1). The old struck-through price keeps the spec's --vs-card-price-old-color (about 2.5:1); a hidden “Regular price:” label is read by screen readers.

Usage — Blade

<x-vs-item-card class="item" :layout="$listView ? 'list' : 'grid'" :title="$item->name" :url="$vsCard->href" :external="$vsCard->external" :image="$item->getPreviewImageLink()" badge="free" :category="$item->subCategory?->name ?? $item->category?->name" :category-url="$item->subCategory?->getLink() ?? $item->category?->getLink()" :description="$item->description" free :stat="translate(':count Downloads', ['count' => numberFormat($item->free_downloads)])" :view-label="translate('View Item')"> {{-- free item: no actions slot, the eye button only --}} </x-vs-item-card> {{-- paid item: add to cart, disabled on the visitor's own item --}} <x-slot:actions> <form data-action="{{ route('cart.add-item') }}" class="add-to-cart-form" method="POST"> <input type="hidden" name="item_id" value="{{ $item->id }}"> <input type="hidden" name="license_type" value="1"> <x-vs-item-card-action icon="fa-solid fa-shopping-cart" :label="translate('Add to cart')" :disabled="authUser() && authUser()->id == $item->author_id" /> </form> </x-slot:actions> {{-- video / audio preview: same .item-video / .item-audio-wave markup the site JS uses --}} <x-vs-item-card ... preview-type="video" :image="$item->getPreviewImageLink()" :preview-url="$item->getPreviewLink()" />

Site contract

  • Grid / list toggle (app.js): pass class="item" and keep the cards inside .items. The toggle adds/removes item-inline on .item, w-100 on its parent, and sets the item_view cookie. The card's list layout follows item-inline.
  • Media JS: .item-video (hover play, volume, fullscreen) and .item-audio-wave (WaveSurfer) markup is kept as on the site, sized to fill the square preview. Or pass your own markup in the media slot.
  • Do not pass Bootstrap's border class (listing pages pass item_classes => 'border' today): its !important colour would hide the hover border.
  • Translations: only keys the old partial already uses go through translate(), so rendering a card never adds rows to the translations table. Button names default to English; pass translated text.
  • Security: every value is printed with {{ }}; the author/category template is split on its placeholders so no item data passes through {!! !!}.
