Foundations // Typography v2.4.0

Typography

Type tokens define the font family, scale, and weight used across VectorSticker.com. Roboto is the single primary font family for both the public frontend and the admin interfaces — replacing the public site's Montserrat override and the report site's Inter.

Fallback stack

Decision: Roboto is the unified font family for all interfaces. Live on reports.vectorsticker.com: the report site's Inter (index.css, index.html), its two standalone /forgot-password and /reset-password pages (previously Plus Jakarta Sans — a third font found only by auditing every real reference), its printable report pages, and its one Canvas chart-label font string have all switched to Roboto.

Not yet on vectorsticker.com. The main site's custom.css still sets font-family: Montserrat !important. Switching it is a separate, tracked follow-up on the main production site, not something this repo changes.
