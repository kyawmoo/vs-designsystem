Typography

One typeface across both products: Roboto. Replaces the public site's Montserrat override and the report site's Inter.

Live on reports.vectorsticker.com; not yet on vectorsticker.com. The report site's Inter (index.css, index.html), its two standalone /forgot-password and /reset-password pages (previously Plus Jakarta Sans — a third font found only by auditing every real reference), its printable report pages, and its one Canvas chart-label font string have all switched to Roboto. vectorsticker.com's custom.css Montserrat override is a separate, tracked follow-up — out of scope for a change made from this repo, since it touches the main production site.
