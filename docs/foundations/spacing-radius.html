01 // Grid Gutter Scale

Grid Gutters

From compact groups to spacious grids.

8px · $spacing-tight · --vs-spacing-sm — compact rows, form field groups
16px · $spacing-default · --vs-spacing-md — default grid gutter (item grids use row g-3 = 16px)
24px · $spacing-loose · --vs-spacing-lg — generous card spacing, dashboard tiles
02 // Section Padding

Section Padding

Vertical rhythm for page sections.

$spacing-section-default · 60px
↕ 60px · --vs-spacing-section-default

Standard top/bottom padding on public pages (home, category feeds).

$spacing-section-compact · 30px
↕ 30px · --vs-spacing-section-compact

Compact sections for dense screens (profile, order history, admin panels).
