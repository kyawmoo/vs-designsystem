03 // Guidelines

Do’s and Don’ts

Keep weight, size and meaning consistent.

DOPair one icon with one clear label, and keep icon size the same across a row (16px, 8px gap).
ExportCategorizeSaveShare
DON’TDon’t mix icon sizes in one group, or stack several icons on one action.
Export Categorize Save/Fav Share
DOUse Solid icons on primary actions such as Download or Add to Cart.
DON’TDon’t use Regular (outline) icons on primary actions — they read as low emphasis.
