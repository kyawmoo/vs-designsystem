01 // Brand Interaction

Primary & Secondary

Buttons, links and focus states.

ValueSemantic nameCSS tokenUse for
#4CAF50$color-interactive-01--vs-color-brand-primaryPrimary buttons, links, form focus border
#222222$color-interactive-02--vs-color-brand-secondarySecondary buttons, dark surfaces

Naming convention: $color-attributeType-attributeVariant. The $… names are aliases for designers; code uses the --vs-* tokens in tokens/tokens.css.
