Shadow

Flat design — no box-shadow anywhere, on either product. Elevation comes only from a 1px border and background-color contrast.

Why

Decided with Master KMO: "Let's fuse flat design." A single token, --vs-shadow-none, exists so any lingering box-shadow in either codebase has an explicit, intentional value to be set to — rather than being silently removed with nothing marking the decision.

reports.vectorsticker.com is now fully shadow-free. Beyond the design-system components (already shadow-free), auditing src/index.css found a real, deliberate box-shadow on three bespoke elements — a floating score tooltip, scatter-plot marker "bubbles" on the Opportunities view, and a list-item hover-lift — plus roughly 40 Tailwind shadow-* utility classes still written across ~15 files. Master KMO confirmed removing all of it for consistency. Removing the three bespoke shadows also surfaced a real bug: a second, later CSS rule targeting the tooltip (added after an earlier flat-design pass) was silently winning the cascade over that pass's own fix, so the tooltip's shadow had never actually been removed — found and fixed in the same pass, confirmed via computed-style checks in a live browser rather than by reading the CSS alone.
