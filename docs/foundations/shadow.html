Shadow

Flat design — no box-shadow anywhere, on either product. Elevation comes only from a 1px border and background-color contrast.

Why

Decided with Master KMO: "Let's fuse flat design." A single token, --vs-shadow-none, exists so any lingering box-shadow in either codebase has an explicit, intentional value to be set to — rather than being silently removed with nothing marking the decision.
